# Publishing and migration status

This repository currently hosts the public landing page, feedback and support pages only.

The **original interactive Crown Land / trails map** remains at:
https://crown-vancouver-explorer.markinzhang7.chatgpt.site/

The hosted map's full source has **not** been exported or merged here. In particular, the requested **default satellite basemap** change has not been applied to the hosted map. This repository does not claim to contain the complete land-data, trail or tiling logic.

To publish these static pages with GitHub Pages:
1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**, branch **main**, folder **/(root)**.
3. Save and monitor the Pages deployment.

To migrate the map completely, obtain its actual source distribution, test data fetching/permissions and preserve all current map features before replacing this landing page.

Donations: Add a verified owner-provided payment URL before offering any payment option. Feedback uses a mailto link and requires visitors to send the drafted email manually.
