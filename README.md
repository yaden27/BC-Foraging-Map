# BC Foraging Map

Community map project for exploring Crown Land candidate areas, trails and terrain in British Columbia.

Current interactive map: https://crown-vancouver-explorer.markinzhang7.chatgpt.site/

This public repository is being prepared for a complete source migration. The original map is still hosted separately; this repository should not yet be treated as the complete map implementation.

Feedback: markinzhang7@gmail.com

Foraging and access restrictions must be checked independently. Mapped boundaries are not proof of access or harvesting permission.
